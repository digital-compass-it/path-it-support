# 🛠️ Path 1: IT Support & Junior System Administrator
### The Fastest, Most Realistic Entry Point into the IT Industry

**Barrier to Entry:** 🟢 Very Low  
**Coding Required:** None to begin (Basic PowerShell / Bash scripting later)  
**Typical Job Titles:** *IT Support Specialist, Helpdesk Technician (Tier 1 / Tier 2), Desktop Support Analyst, Junior System Administrator*

---

## 🎯 Why Start Here?
Every single company in the world relies on computers, networks, cloud accounts, and software – and things break every day. 

Companies actively hire career changers for IT Support because **patience, clear communication, and structured troubleshooting** are far harder to teach than how to reset a password or configure a printer. Once you are inside an IT department, you can grow into **SysAdmin, Cybersecurity, or Cloud Engineering** while getting paid.

---

## 🗺️ Step-by-Step Learning Roadmap (8–12 Weeks)
*100% free, official vendor training – no paid platforms or third-party bootcamps required.*

### Phase 1: Windows Client, Hardware & OS Basics (Weeks 1–2)
Before you can fix computers, you need to understand how Windows works under the hood and how to troubleshoot everyday user issues.
* [ ] Understand basic PC hardware components (CPU, RAM, Storage, BIOS/UEFI) and how they interact with the OS.
* [ ] Master Windows 10/11 administration (Task Manager, Event Viewer, Device Manager, Disk Management, Safe Mode).
* [ ] Learn basic command-line troubleshooting (`cmd` and basic Linux shell navigation).
* **Free Official Resource:** 
  * 🎓 **Microsoft Learn – Windows Client Administration & Troubleshooting Modules** *(100% free, practical, step-by-step official Microsoft training)*

### Phase 2: Practical Networking Fundamentals (Weeks 3–4)
80% of IT support tickets involve "the internet or network isn't working." You do not need dry academic network theory – you need practical troubleshooting skills.
* [ ] Understand IP addresses (IPv4/IPv6), Subnet Masks, Default Gateways, MAC addresses, and common Ports (HTTP, HTTPS, RDP, SSH, DNS).
* [ ] Know how DNS, DHCP, Wi-Fi, VPNs, and Windows Firewall work in real office environments.
* [ ] Practice essential diagnostic commands (`ping`, `tracert`, `ipconfig /all`, `nslookup`, `netstat`).
* **Primary Free Resource (Recommended):** 
  * 🎓 **Microsoft Learn – Windows Server Networking & Core Networking Infrastructure** *(No login required to start reading immediately; clear, practical, and directly applicable)*
* **Optional Deep-Dive (For Later):** 
  * 📚 *Cisco Networking Academy (Networking Basics)* – Very thorough if you want to specialize in pure network engineering later, **but be warned:** the platform frequently changes its portal structure and login flow, and the theory is heavy for beginners. Start with Microsoft Learn first!


### Phase 3: Identity, Microsoft 365 & Cloud Administration (Weeks 5–8)
Modern companies manage their employees, emails, and security through Microsoft environments. Knowing your way around here makes you immediately employable.
* [ ] Understand Active Directory (AD) and Microsoft Entra ID (formerly Azure AD): creating users, resetting passwords, managing groups and permissions.
* [ ] Learn Microsoft 365 administration basics (Exchange email, Teams, OneDrive, licensing).
* [ ] Understand endpoint management basics (Microsoft Intune) and IT ticketing workflows.
* **Free Official Resources:** 
  * 🎓 **Microsoft Learn – MS-900: Microsoft 365 Fundamentals** *(Complete free learning path)*
  * 🎓 **Microsoft Learn – SC-900: Security, Compliance, and Identity Fundamentals** *(Essential basics on Entra ID & permissions)*
  * 🎓 **Microsoft Learn – MD-102: Endpoint Administrator Learning Path** *(Deep dive into modern Windows & device support)*

### Phase 4: PowerShell Basics & Automation (Weeks 9–10)
Once you know how to click through admin panels, learning a few basic commands will set you apart from 90% of other entry-level applicants.
* [ ] Learn basic PowerShell commands (`Get-Help`, `Get-Process`, `Get-Service`, `Get-ADUser`).
* [ ] Understand how to automate simple repetitive support tasks.
* **Free Official Resource:** 
  * 🎓 **Microsoft Learn – Introduction to PowerShell** *(Includes free interactive sandbox environment in your browser)*

## 🛠️ Hands-On Home Lab: Build Your Proof of Skills
Certificates get you noticed, **practical projects get you hired**. Set up these 3 free projects on your own computer (or Raspberry Pi) and put them on your CV:

- [ ] **Project 1: Virtualization Lab** – Install **VirtualBox** (free) and run a Windows 11 and an Ubuntu Linux virtual machine on your PC.
- [ ] **Project 2: Active Directory Simulation** – Install a free evaluation version of **Windows Server** in VirtualBox, promote it to a Domain Controller, and create 5 test users and security groups.
- [ ] **Project 3: Network Ad-Blocker / DNS Server** – Set up **Pi-hole** (either on a Raspberry Pi or inside a Linux VM) to see real-time DNS requests in action.

---

## 📄 How to Present Yourself on Your CV (Even Without IT Experience)
* **Highlight Soft Skills:** Emphasize customer service, de-escalation, documentation, and working under pressure from your previous jobs.
* **Add a "Technical Home Lab" Section:** List your VirtualBox, Windows Server / Active Directory, Linux, and Pi-hole setups as practical hands-on experience.
* **Show Your Official Badges:** Link your free Microsoft Learn trophies/achievements and Cisco digital badges directly on your LinkedIn profile.
